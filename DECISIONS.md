# Variety Matters Redux: decisions

Design decisions for Variety Matters Redux. Each entry is a typed definition
(`⟦def decision:<name>⟧`) carrying its status, the adopted choice, the
rationale, rejected alternatives and when to revisit. When an answer changes,
edit the entry in place and note the date in its status; cite entries
elsewhere as `⟦decision:<name>⟧`. Evyatar's answers to design studies, agent
playtest proposals and player suggestions are recorded here (see
`D:\MyRimworldMods\ModWorkspace\DESIGN-STUDIES.md`).

## Decision record

`⟦def decision:decision-record-location⟧`

- status: adopted 2026-10-17 (Evyatar).
- Adopted: this file is Variety Matters Redux's decision record, with typed decision tags,
  the same convention as Pain Matters and the mod hub.
- Rationale: design studies, agent playtests and player suggestions all end
  in a decision only Evyatar makes, and agents in later sessions need to find
  it. Pain Matters' `DECISIONS.md` is what kept its agents consistent.
- Rejected: decisions kept only in board tasks or roadmap notes, which get
  closed or go stale; plain-prose entries (Evyatar chose typed tags).
- Revisit if the mod moves its design records elsewhere.
